📅 Configurar Google Calendar

Para sincronizar las instalaciones con Google Calendar sigue estos pasos:

1
Crear proyecto en Google Cloud Console

Ve a console.cloud.google.com → Nuevo proyecto → Nombre: "TopRedes"

2
Activar la API de Google Calendar

APIs y servicios → Habilitar APIs → busca "Google Calendar API" → Activar

3
Crear credenciales OAuth 2.0

Credenciales → Crear credenciales → ID de cliente OAuth → Tipo: Aplicación web → URI autorizado: tu URL de Netlify
