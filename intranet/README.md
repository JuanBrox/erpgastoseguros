## 🚀 Deploy en Netlify

### Opción A — Arrastrar ZIP
1. Ve a [netlify.com](https://netlify.com) → *Add new site* → *Deploy manually*
2. Arrastra el ZIP con todos los ficheros
3. URL pública generada automáticamente

### Opción B — Conectar GitHub (recomendado)
1. Sube este repo a GitHub
2. En Netlify → *Add new site* → *Import from Git*
3. Selecciona el repositorio
4. Build settings: dejar en blanco (sitio estático puro)
5. Publish directory: `.` (raíz)
6. Deploy

### Proteger con contraseña (recomendado para intranet)
En Netlify Dashboard → **Site configuration** → **Access control** → **Basic password protection**
